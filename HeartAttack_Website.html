About This Project
Built as a BCA-Hons AI&ML Project by Atul Anand , Viswesh M , Lakshita

🛠️ Tech Stack

  • Language: Python 3
  • Algorithm: Multi-Output Random Forest Regressor
  • Libraries: Scikit-learn, NumPy, Pandas
  • Visualization: Matplotlib, Seaborn
  • Platform: Google Colab
  • Website: HTML5, CSS3, Vanilla JS

📈 Model Performance

  • Stenosis R²: 0.71
  • Artery Diameter R²: 0.74
  • Cholesterol R²: 0.68
  • Blood Pressure R²: 0.66
  • BMI R²: 0.67
  • Risk Score R²: 0.80 ⭐ Best

📋 Input Parameters

  • Age: 30–80 years
  • Smoking: Yes / No
  • Exercise Level: 0 (None) to 4 (Very High)
  • Diet Score: 1 (Poor) to 10 (Excellent)
  • Family History: Yes / No

📤 Output Parameters

  • Stenosis %: Coronary artery blockage
  • Artery Diameter: In millimeters
  • Cholesterol: mg/dL
  • Blood Pressure: mmHg
  • Heart Rate: Beats per minute
  • BMI: Body Mass Index
  • Risk Score: 0–100 composite

⚠️ This is an educational project using synthetic data. Not for clinical use.
